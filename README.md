# 🏦 BancoAula.Api

API RESTful de simulação bancária desenvolvida em C# e .NET (ASP.NET Core Controllers), com operações de CRUD.

> 🚧 **Status do Projeto:** Em desenvolvimento (estrutura inicial configurada).

## 💻 Tecnologias Utilizadas

O projeto está sendo construído, e, conforme avançar, as tecnologias e ferramentas utilizadas serão listadas aqui:

- **Linguagem:** C#
- **Framework:** .NET 10 / ASP.NET Core Web API (Controllers)
- **Paradigma & Estilo Arquitetural:** Programação Orientada a Objetos (OOP) e API RESTful
- **Controle de Versão:** Git e GitHub
- **Ambiente de Desenvolvimento:** VS Code

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter os seguintes itens instalados na sua máquina:
* [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
* Um editor de código de sua preferência (ex: **VS Code**)

## 📥 Como Instalar e Executar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/fullEdvan/BancoAula.Api.git
2. **Acesse a pasta do projeto:**
   ```bash
   cd BancoAula.Api
3. **Execute a aplicação:**
   ```bash
   dotnet run
